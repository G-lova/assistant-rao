# AI Assistant RAO

AI-ассистент для анализа документов закупок.



## Описание проекта

Проект предоставляет инструменты для:
- Анализа документов закупок на соответствие требованиям
- Выявления проблем и несоответствий
- Формирования отчетов о проверке
