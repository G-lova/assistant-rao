Ты анализируешь изображение документа (скан, фото, схема, товар, результат работ).

ТВОЯ ЗАДАЧА:
1. Определи, есть ли на изображении ЧИТАЕМЫЙ ТЕКСТ.
2. Если текст есть:
   - has_text = true
   - raw_text = весь распознанный текст в порядке чтения; абзацы и строки разделяй переводом строки (\n);
     таблицы — по правилам раздела ТАБЛИЦЫ
   - visual_notes = описание визуальных элементов (подписи, печати, штампы, водяные знаки, рукописные элементы), если присутствют, иначе пустая строка
   - image_description = ""
3. Если текста нет:
   - has_text = false
   - raw_text = ""
   - visual_notes = ""
   - image_description = краткое описание изображения

4. Оцени качество OCR.

ОБЯЗАТЕЛЬНО верни СТРОГО валидный JSON следующей структуры:

{
  "has_text": true | false,
  "raw_text": "весь распознанный текст: абзацы через \\n, таблицы — строками с ячейками через « | » (если has_text=true, иначе пустая строка)",
  "visual_notes": "описание визуальных элементов (подписи, печати, штампы, водяные знаки, рукописные элементы)",
  "image_description": "краткое описание изображения (если has_text=false, иначе пустая строка)",
  "processing_quality": {
    "status": "high|medium|low",
    "ocr_score": <0.0–1.0>,
    "issues": ["перечень проблем распознавания, если есть"]
  }
}

ТАБЛИЦЫ:
- Таблицу выводи внутри raw_text на её месте в тексте: строка «Таблица N:», затем каждая строка таблицы с новой
  строки, ячейки через « | », первой — строка заголовков. Например:
  Таблица 1:
  Наименование | Количество | Ед. изм. | Характеристики
  Ноутбук | 10 | шт. | Диагональ не менее 15,6"
- Число ячеек в каждой строке — как в заголовке; пустую ячейку оставляй пустой между « | », объединённую ячейку
  повтори в каждой строке, к которой она относится.
- Значения переноси точно как в документе (числа, единицы, знаки ≥ ≤ ±), ничего не пересчитывай и не сокращай.
- Таблицу, продолжающуюся с прошлой страницы без заголовка, выводи строками так же, без повторной строки «Таблица N:».

ПРАВИЛА:
- НЕ выдумывай текст, если его нет.
- НЕ добавляй markdown и пояснения (кроме разметки таблиц выше и переводов строк).
- Никаких дублей.
- Если текст частично читаем — has_text=true, но снижай ocr_score и укажи проблемы в issues.
- Если проблемы с распознаванием изображения, укажи их в issues, снижай ocr_score.
- Все поля обязательны.
