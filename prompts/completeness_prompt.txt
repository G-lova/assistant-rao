## 1. КЛАССИФИКАЦИЯ (type_compliance)

Определи тип документа.

**Правила:**

- В detected_type верни **только ключ из словаря {mapping}**
- Если не подходит → `"unknown"`
- Если есть точное название (кроме "контракт") → сразу классифицируй
- "Контракт" → анализируй по содержанию

**Разграничения:**

- Проект контракта → нет реквизитов, шаблон
- Контракт → есть номер, дата, стороны, сумма, подписи

**Статус:**

- `"allow"` — тип совпадает с ожидаемым
- `"deny"` — нет (указать причину в issues)
- Исключение: если ожидался проект, а это контракт → allow

**confidence** снижай при плохом OCR или малом тексте

**Основные типы (смысл)**

- 'docIzvejenieFiles' (Извещение) → объявление закупки (если это html документ, то название ищи в <body>)
- 'docOpusObjectZacupFiles' (Описание объекта) → характеристики
- 'docObosnNMCKFiles' (Обоснование НМЦК) → расчет цены
- 'docMaterialValidNMCKFiles' (Подтверждение НМЦК) → источники цен
- 'docContractDoWorkFiles' / 'docContractNIRFiles' / 'docContractPostTovarFiles' (Контракт) → подписанный договор
- 'docProjContractFiles' (Проект контракта) → шаблон
- 'docPriemTovSchetFiles' (Приемка) → акт, УПД
- 'docCargoTaxFiles' (Накладная) → ТОРГ-12
- 'docValidGarantFiles' (Гарантии) → гарантийные письма
- 'docTechDocFiles' (Техдок) → паспорта, инструкции
- 'docValidAllIfFiles' (Исполнение) → акты, отчеты
- 'docVziskPenyFiles' (Штрафы) → претензии
- 'docTrebContentRequestFiles' (Инструкция) → инструкция по заполнению заявки

## 2. ЧИТАЕМОСТЬ (readability)

Очисти текст:

- убрать мусор, разрывы строк, лишние символы, html разметку

Оцени:

- язык: ISO (ru)
- readability_score ≥ 0.7 → allow
- readability_score < 0.7 → deny
- не русский → deny

Важно:

- для проекта контракта отсутствие реквизитов — норма

## 3. ИЗВЛЕЧЕНИЕ ДАННЫХ (raw_data)

Извлеки:

- document_name
- contract_number
- dates [{value, context}]
- amounts [{value, currency, context}]

### НМЦК

- method: (среднерыночный / тарифный / и т.д.)
- assessment: корректность расчета

### Организации

- role: заказчик / поставщик / участник
- name, inn, kpp, ogrn, address

### Закон

- ссылки: "44-ФЗ", "223-ФЗ", статьи

### Предмет закупки

- описание
- items [{name, quantity, unit, specifications}]

### Сроки

- start_date / end_date
- duration
- milestones

### Отчетность

- required_reports [{name, frequency, deadline, format}]

### Место

- address
- special_conditions

### Прочее

- other_data ["в том числе подписи"]
