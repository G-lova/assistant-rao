# ФОРМАТ ОТВЕТА

- Только JSON, без текста вне его.
- Все поля обязательны.
- Без дублей.
- Язык русский.

# ПРАВИЛА ЗАПОЛНЕНИЯ 

1. `type_compliance`:

    `status`:
    - **allow**, если хотя бы один документ соответствует ожидаемому типу,
    - **deny**, если ни один документ не соответствует ожидаемому типу

    в `description` указать, если у каких-либо документов есть несоответствия с ожидаемым типом

2. `readability`: 

    `status`:
    - **allow**, если общая читабельность документов данного типа в порядке,
    - **deny**, если имеются критические ошибки в читабельности документов данного типа
    
    в `description` опиши проблемы, если присутствуют

3. `completeness`:

## `status`:

Оценивай ТОЛЬКО документы данного типа (`doc_type`), переданные в `documents`.
Отсутствие документов других типов (например, «Обоснование НМЦК») НЕ учитывай и НЕ упоминай:
оно влияет только на итоговую оценку комплекта, а не на полноту данного типа.

**allow**, если среди документов данного типа есть хотя бы один подходящий документ, данных которого
достаточно (есть обязательные реквизиты типа) и которые не нарушают 44-ФЗ / 223-ФЗ и не противоречат экспертизе.
Остальные документы этого типа (например, нечитаемые или неподходящие) не меняют статус: отметь их
в `description` как замечание.

**deny**, если НИ ОДИН документ данного типа не даёт достаточных данных:

- отсутствуют ключевые реквизиты
- тип не соответствует содержанию
- документ пуст / нерелевантен
- данные нарушают 44-ФЗ / 223-ФЗ


## `description` (обязательно указать):

    - наличие/отсутствие обязательных реквизитов
    - ошибки / противоречия
    - соответствие параметрам экспертизы
    - соответствие содержания типу
    - 1-2 предложения

## ОБЯЗАТЕЛЬНЫЕ РЕКВИЗИТЫ (по типам)

**Ссылка на ЕИС" ("linkDocs"):**
ссылка доступна, ведет на `zakupki.gov.ru`, присутствует цифровой номер ("regNumber" / "reestrNumber" / "noticeInfoId" / "contractInfoId" / "orderId")

**Невозможность закупки:**
обоснование, ссылка на ст. 93 (44-ФЗ/223-ФЗ), описание объекта, поставщик (ИНН/ОГРН), дата, подпись

**Приемка товара / акт:**
стороны, дата/место, товар (кол-во, ед., характеристики), результат проверки, подписи, номер

**Положение (223-ФЗ):**
планирование, способы закупки, комиссия, публикация, условия контрактов, обжалование

**Накладная:**
стороны, товары (кол-во, цена), единицы, дата, номер, подписи

**Сертификат:**
продукция, номер/дата, срок, стандарт, орган, знак

**Контракт (работы/услуги):**
предмет, цена, сроки, ответственность, приемка, стороны, реквизиты, подписи

**Контракт НИР:**
этапы, результаты, ИС, отчетность

**Контракт поставки:**
характеристики товара, условия поставки, гарантия

**Акт работ/услуг:**
стороны, объем, дата, соответствие, подписи, номер

**Допсоглашение:**
ссылка на контракт, изменения, основание, подписи, дата

**Экспертиза:**
комиссия, цель, выводы, соответствие, рекомендации, подписи

**Извещение:**
название, способ, НМЦК, сроки, требования, объект, контакты

**Обоснование НМЦК:**
метод (ст. 22), расчет, источники, утверждение

**Подтверждение НМЦК:**
источники цен, расчеты, дата, подпись

**Описание объекта:**
характеристики, требования, условия

**Оценка заявок:**
критерии, методика, комиссия, сроки

**Проект контракта:**
шаблон контракта (отсутствие реквизитов — это норма)

**НИР отчет:**
этапы, результаты, выводы, подписи

**Техдок:**
характеристики, производитель, гарантия, стандарты

**Заявка (требования):**
перечень документов, форма, инструкция, сроки

**Исполнение контракта:**
акты, экспертиза, оплата, устранение замечаний

**Авторские права:**
объекты ИС, передача, срок, подписи

**Происхождение товара:**
сертификат/декларация

**Гарантия:**
срок, условия, реквизиты, подпись

**Штрафы:**
расчет, ссылка на контракт/закон, претензия
