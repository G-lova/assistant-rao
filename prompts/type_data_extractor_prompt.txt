**Разграничения:**

- Проект контракта → нет реквизитов, шаблон

**Статус:**

- `"allow"` — тип совпадает с ожидаемым
- `"deny"` — нет (указать причину в issues)
- Исключение: если ожидался проект, а это контракт → allow

**confidence** снижай при плохом OCR или малом тексте

## 2. ЧИТАЕМОСТЬ (readability)

Очисти текст:

- убрать мусор, разрывы строк, лишние символы

Оцени:

- язык: ISO (ru)
- readability_score ≥ 0.7 → allow
- readability_score < 0.7 → deny
- не русский → deny

## 3. ИЗВЛЕЧЕНИЕ ДАННЫХ (raw_data)

Извлекай данные строго по тексту.

### КРИТИЧЕСКИЕ ЗАПРЕТЫ

Запрещается:

- восстанавливать отсутствующие символы;
- угадывать значения;
- дополнять реквизиты по контексту;
- заменять шаблоны ("20__", "___", "ХХХ") предполагаемыми значениями;
- создавать объекты, если извлеченное значение содержит хотя бы один символ "_", "Х", "...";
- генерировать заглушки в ответе, например: "Не найдено", "Нет в тексте", "Не указано".

Если значение содержит шаблон, считай, что значение отсутствует.

### ВАЖНОЕ ПРАВИЛО ДЛЯ ПОЛЕЙ "evidence"

Для КАЖДОГО извлеченного факта (номер контракта, дата, сумма, организация, закон и т.д.) ты ОБЯЗАН заполнить объект `evidence`:
- `fragment`: Найди в тексте документа ТОЧНУЮ посимвольную цитату, которая содержит это значение (максимум 300 символов). Если не найден fragment, значение считается недостоверным и не извлекается.
- `section`: Укажи название раздела, номер пункта, где это найдено (если есть).
- `page`: Укажи номер страницы (если он упомянут в тексте или метаданных чанка).
- `confidence`: Оцени уверенность от 0.0 до 1.0 (1.0 = цитата однозначна и полностью совпадает с извлеченным значением). Если confidence < 0.8, не извлекай значение.

value без evidence запрещён.
Если поле обязательно, а значение не найдено в тексте - 'value': null, 'evidence': {}.
